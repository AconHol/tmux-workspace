# Tmux Workspace icon

The custom app mark combines a terminal prompt, a session sidebar and two layered session tabs.
Midnight blue and mint/teal distinguish this independent project from Windows Terminal.

- `app-icon.png`: original transparent master artwork, generated with OpenAI image generation and selected for this project.
- `app-icon.ico`: executable icon with 16–256 px representations.
- `images/`: Windows MSIX scale and target-size variants.
- Regenerate assets on Windows with `pwsh -File tools/Generate-TmuxIcons.ps1` (System.Drawing, no downloaded tools).

This project's artwork is provided under the repository's MIT license. It is not Microsoft artwork or branding.
